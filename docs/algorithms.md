# 算法与控制规则

倾角实现：firmware/USER/tilt.c；评分实现：firmware/USER/risk.c。

## 默认分档

每项使用三条边界，将值分为0/1/2/3分。

| 指标 | 边界 | 权重 |
| --- | --- | --- |
| 5秒平均位移相对人工基准的绝对变化 | 0.5 / 2 / 5 mm | 32% |
| 土壤相对湿度 | 30 / 60 / 80 % | 28% |
| 雨滴板湿润度 | 20 / 50 / 80 % | 20% |
| 合成倾角相对人工基准的绝对变化 | 0.2 / 0.5 / 1.5 ° | 12% |
| 昨天＋今天＋明天累计降水 | 20 / 50 / 150 mm | 8% |

总分为各单项分数的加权和。总分≥2或位移/倾角达到3档为实验危险；未达危险时，总分>1或形变项达到2档为实验预警；其余完整有效数据为实验安全。通常连续两个新有效窗口确认等级变化；缺测、运动干扰及无基准单独处理。

此处“安全”是原型界面等级名称，不表示现场安全。实际参数应通过传感器标定、场景数据和独立验证确定，不能直接作为滑坡预警标准。

## 数据有效性

- 5秒窗口必须有有效、配对的位移与倾角输入。
- 基准由K-UP人工确认，保存在RAM，重启后重新设置。
- 天气帧校验、时区、日期窗口、数值边界均需通过；超过一小时或北京时间跨日失效。
- 新WX3C帧代表昨今明窗口，拒绝旧WX3范围，以避免误把未来三日数据当作新窗口。
- 昨天的数据与今天/明天的模型估计混合使用，并非三天现场实测累计。
- 缺测不按0分计算，不自动重分配权重。

## 报警优先级

危险持续响，预警间歇响；自动报警有效时不能由手动关闭覆盖。自动报警未激活时，K1依次切换间歇、持续、静音。云端bool开关控制手动持续试鸣/关闭，实际执行结果需等待设备回执。
