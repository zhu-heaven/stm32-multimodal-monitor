# 接线与操作

原型：STM32F407VE、240×320 ST7789 SPI显示模块、MPU6050、模拟位移/雨滴/土壤湿度、三脚高电平触发有源蜂鸣器、4G DTU和USB-TTL。按模块丝印及实际板卡确认，断电接线。

| 外设 | 模块端 | STM32端 |
| --- | --- | --- |
| LCD | SCK / DIN / RST / DC / CS / BL | PB5 / PB6 / PB7 / PB8 / PB9 / PB10 |
| LCD | VCC / GND | 3.3V / GND，背光控制按实际模块电路 |
| MPU6050 | SCL / SDA | PB11 / PB12，3.3V上拉 |
| MPU6050 | VCC / GND / AD0 | 3.3V / GND / GND |
| 位移电位器 | 滑动端 | PC0；固定两端接3.3V和GND，必须按实际端子图识别 |
| 雨滴模块 | AO | PC1，模块3.3V供电 |
| 土壤模块 | AO | PC2，模块3.3V供电 |
| 有源蜂鸣器 | IO | PA8，高电平触发；VCC按模块额定值，GND共地 |
| USB转TTL | RXD / TXD / GND | PA9 / PA10 / GND，3.3V TTL |
| 4G DTU | RXD / TXD / GND | PA2 / PA3 / GND，串口逻辑电平按模块规格匹配 |

PC0/PC1/PC2模拟输入限制在0～3.3V。4G模块按其板卡额定范围独立供电，不把5V电源直接接到仅支持低压的模组VIN。独立电源负极与开发板共地。

## 板载按键

- K0（PE4）：传感器 → 天气 → 评分三页循环。
- K1（PE3）：自动报警未激活时，间歇 → 持续 → 静音试鸣。
- K-UP（PA0）：静止后确认位移与倾角基准；重启后重新确认。

位移和湿度端点均需按自己硬件标定，现有常量是原型配置，不保证换一套传感器后的精度。
