# 模块与数据流

1. 模拟传感器经ADC采集；MPU6050经软件I²C读取。
2. MCU执行滤波、同步窗口和人工基准相对变化计算，再做实验评分与报警。
3. 1ms SysTick支撑按键消抖、毫秒计时与蜂鸣器节拍，避免LCD刷新阻塞声型。
4. USART1与C#电脑工具交换监测文本、天气校验帧；电脑负责互联网天气查询。
5. USART2连接DTU，DTU负责MQTT连接，MCU发送OneJSON业务数据并解析控制消息。
6. 服务端用自己的OneNET凭据查询属性与历史；浏览器只访问服务端接口。
7. 管理员操作经过认证、参数校验、下发和设备回执，自动报警具有更高优先级。

公开代码保持当前模块边界与主要功能。运行环境、外设接线、传感器校准与第三方服务配置需由复现者独立完成。
